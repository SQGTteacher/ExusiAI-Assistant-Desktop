# ExusiAI 文件查看器

阶段 1 提供 `.txt`、`.md`、`.markdown` 和 `.csv` 的安全只读预览。阶段 2A 新增 `.docx` 正文结构化文本预览并建立 Open XML ZIP/XML 安全边界；阶段 2B 新增 `.xlsx` 首工作表分页预览、共享字符串和基础单元格值读取；阶段 2C 新增 `.pptx` 幻灯片顺序发现与逐页结构化文本预览。文本按 64 KiB 增量解码，界面缓存限制为 8 MiB；CSV 按 256 行分页，列表启用回收式虚拟化。所有读取均可取消且不在 UI 线程执行文件 I/O。

DOCX 当前不提供 Word 高保真分页；XLSX 当前不计算公式，仅显示缓存值，且不处理样式/日期格式、合并单元格、图表、批注、宏、外部链接或多工作表切换；PPTX 当前不提供高保真版式、图片/图表/SmartArt/动画/媒体渲染；DOC、XLS、PPT、RTF 尚未实现。插件不会执行宏、脚本或外部内容，也不会声称对这些能力提供兼容。完整边界见 `docs/file-viewer/compatibility-matrix.md`。
