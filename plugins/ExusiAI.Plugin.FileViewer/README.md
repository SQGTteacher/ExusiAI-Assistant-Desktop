# ExusiAI 文件查看器

阶段 1 提供 `.txt`、`.md`、`.markdown` 和 `.csv` 的安全只读预览。阶段 2A 新增 `.docx` 正文结构化文本预览并建立 Open XML ZIP/XML 安全边界；阶段 2B 新增 `.xlsx` 首工作表分页预览、共享字符串和基础单元格值读取；阶段 2C 新增 `.pptx` 幻灯片顺序发现与逐页结构化文本预览；阶段 3A 增加上一页/下一页/页码随机跳转与有界幻灯片缓存；本轮课堂工作流批次进一步加入 TXT/Markdown/DOCX/CSV/XLSX/PPTX 全文搜索、搜索结果跳转、最近文件快速重开、PPTX 邻页后台预热，以及打开/切页/搜索耗时反馈。文本按 64 KiB 增量解码，界面缓存限制为 8 MiB；CSV 按 256 行分页，列表启用回收式虚拟化。所有读取均可取消且不在 UI 线程执行文件 I/O。

DOCX 当前不提供 Word 高保真分页；XLSX 当前不计算公式，仅显示缓存值，且不处理样式/日期格式、合并单元格、图表、批注、宏、外部链接或多工作表切换；PPTX 当前不提供高保真版式、图片/图表/SmartArt/动画/媒体渲染；DOC、XLS、PPT、RTF 尚未实现。插件不会执行宏、脚本或外部内容，也不会声称对这些能力提供兼容。完整边界见 `docs/file-viewer/compatibility-matrix.md`。


## 查看器界面

独立窗口采用面向课堂展示的 Fluent 风格工作区：顶部紧凑命令栏承载打开、最近文件、搜索与格式相关操作；中央尽量保留给文档画布；搜索结果作为可关闭的右侧辅助窗格；底部状态栏显示安全状态、读取/切页/搜索耗时和缩放。视觉层级参考 Microsoft 365 / Fluent 的信息组织方式，但不复制其专有素材或品牌资源。


## 启动行为

插件工作台中的“文件查看器”现在仅显示基础入口、最近文件和安全说明，不会在选中插件时自动弹出查看窗口。只有用户明确选择文件或点击最近文件后，才创建独立的 Fluent 文档查看窗口。
