# ExusiAI Assistant Desktop 0.1.0developer beta

> **请勿使用此版本用于生产环境，仅做开发者参考。**
>
> This is a developer beta. Do not use it in production; it is provided for developer reference only.

本次预发布面向开发者进行功能体验、插件适配和问题排查，不承诺生产稳定性或配置兼容性。测试前请备份现有数据，使用单独的测试环境。

## 下载与运行

- 平台：Windows x64。
- 包体：自包含 ZIP，完整解压后运行 `ExusiAI.Desktop.exe`，请保留同目录的 `packages` 和 `viewer` 文件夹。
- 标签：`v0.1.0-developer-beta`；程序集产品版本：`0.1.0-developer-beta`。
- 随包提供 SHA-256 校验值、构建来源和本说明。

## 本版本内容

- ClassIsland 原版 Avalonia 界面在宿主进程内运行，支持反复启停、设置保存及托盘入口。
- 修复停用后的计时器、Cron 与自动化残留；等待异步退出动作完成，阻止旧会话覆盖新设置。
- 包含文件查看器、点名和桌宠插件；文件查看器使用进程内 Office/PDF 解析与视频解码组件。
- 包体不包含外部 ClassIsland.exe、LibreOffice、ArkPets.exe 等第三方可执行程序。

## 开发者说明

产品发布编号与扩展兼容级别分别维护。本版本沿用 `0.2.0-preview.4` 扩展宿主兼容级别和 API `1`，现有内置插件清单无需降级。
CLR 程序集标识保持 `0.2.0.0`，以便现有插件继续解析共享契约；产品与文件版本使用本次 Beta 编号。

发布前必须通过 Windows 构建、测试、自包含包运行和三轮 ClassIsland 启停验证。以对应 CI 记录及包内构建来源为准。
