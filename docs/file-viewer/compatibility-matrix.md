# 文件查看器兼容矩阵

此表描述当前已发布能力，不代表长期目标。“识别”不等于“高保真支持”。

| 格式 | 当前状态 | 读取策略 | 搜索/跳转 | 编辑/保存 | 明确边界 |
|---|---|---|---|---|---|
| TXT | 阶段 1 可用 | 异步增量解码；64 KiB 块；UI 最多缓存 8 MiB | 全文流式搜索；结果定位到已缓存文本 | 只读 | UTF-8/带 BOM 编码；非法编码安全报错 |
| Markdown | 阶段 1 可用 | 与 TXT 相同，显示源文本 | 全文流式搜索；结果定位到已缓存文本 | 只读 | 不渲染/执行 HTML、脚本或外部内容 |
| CSV | 阶段 1 可用 | 异步解析；256 行分页；回收式 UI 虚拟化 | 全表流式搜索；结果跳转到所在分页 | 只读 | 支持引号、转义引号、字段内换行；字段数和字段长度有安全上限 |
| RTF | 未实现 | 无 | 无 | 只读/不可打开 | 尚未评估安全解析器与高保真边界 |
| DOCX | 阶段 2A+ 可用 | ZIP/XML 安全预检；标题、列表、段落与表格行结构化流式读取 | 结构化正文全文搜索；结果定位到已缓存文本 | 只读 | 不提供 Word 高保真分页；复杂排版、图片、字体替换、公式、图表、批注、修订、外部链接、嵌入对象均不渲染或执行 |
| XLSX | 阶段 2B+ 可用 | ZIP/XML 安全预检；工作表切换；当前工作表按 256 行分页；共享/内联字符串与基础值读取 | 当前工作表全文搜索；结果跳转到所在分页 | 只读 | 不计算公式，仅显示缓存值；复杂样式/日期格式、合并单元格、图表、批注、宏、外部链接不渲染或执行 |
| PPTX | 阶段 2C 可用 | ZIP/XML 安全预检；按演示文稿顺序逐页提取 DrawingML 文本 | 全演示文稿文本搜索；上一页/下一页/页码跳转；邻页预热；缩略图待后续 | 只读 | 不提供 PowerPoint 高保真版式；图片、图表、SmartArt、动画、转场、媒体、批注、宏、外部链接、嵌入对象不渲染或执行 |
| DOC/XLS/PPT | 未实现 | 无 | 无 | 只读/不可打开 | 旧二进制 Office 格式；必须先确定隔离式适配器方案 |

## 安全默认值

- 单文件默认上限 512 MiB；CSV 单字段默认上限 1 MiB、单行最多 16,384 字段。
- Open XML 默认最多 4,096 个 ZIP 条目、单条目 256 MiB、总展开 1 GiB、压缩比 200:1、单 XML 文档 64 Mi 字符；XLSX 单行最多 16,384 列、共享字符串表最多 1,000,000 项；PPTX 默认最多 2,000 张幻灯片、每页最多提取 2 Mi 字符。
- 当前 Provider 仅以共享只读方式打开文件，不写入源文件。
- 宏、脚本、外部链接、网络资源、OLE 和嵌入对象一律不执行。
- Open XML 仅流式读取所需部件，不解压到磁盘；禁止 DTD 和外部实体，不解析外部关系。
