# 文件查看器兼容矩阵

此表描述当前已发布能力，不代表长期目标。“识别”不等于“高保真支持”。

| 格式 | 当前状态 | 读取策略 | 搜索/跳转 | 编辑/保存 | 明确边界 |
|---|---|---|---|---|---|
| TXT | 查看 + 基础编辑可用 | 异步增量解码；64 KiB 块；UI 最多缓存 8 MiB；磁盘外部更改提示 | 全文搜索；F3/Shift+F3 循环结果；编辑状态下搜索当前内存文本；行/词/字符/光标位置统计 | 文本编辑、保存、另存为、撤销/重做；原子替换；冲突覆盖确认 | 支持 UTF-8 与常见 BOM 编码；超过 8 MiB UI 缓存时自动禁用编辑，避免截断保存 |
| Markdown | 排版预览 + 源码编辑可用 | 与 TXT 相同；排版预览最多 1 Mi 字符/2,000 区块，支持标题、段落、列表、引用、代码、分隔线和基础行内强调 | 标题大纲；全文搜索；F3/Shift+F3 循环结果；逻辑行跳转；文本统计 | 预览/源码切换；源文本编辑、保存、另存为、撤销/重做；原子替换；冲突覆盖确认 | HTML 标签按普通文本处理；不加载图片、链接目标、脚本或网络资源；不提供所见即所得写作 |

| DOC | 受限文本读取 | 程序内 HWPF 解析 | 正文搜索 | 只读 | 尚不保留原始排版、图片和分页 |

| XLSX | 阶段 2B+ 可用 | ZIP/XML 安全预检；工作表切换；当前工作表按 256 行分页；共享/内联字符串与基础值读取 | 当前工作表全文搜索；结果跳转到所在分页 | 只读 | 不计算公式，仅显示缓存值；复杂样式/日期格式、合并单元格、图表、批注、宏、外部链接不渲染或执行 |

## 安全默认值

- 单文件默认上限 512 MiB；CSV 单字段默认上限 1 MiB、单行最多 16,384 字段。
- 二进制 PPT 转换默认最多 16 MiB，串行执行；编辑历史拒绝循环及超过 4,096 条记录。转换过程中取消会等待库释放资源后清理；输入预算不等同于恶意文件的进程隔离沙箱。
- Open XML 默认最多 4,096 个 ZIP 条目、单条目 256 MiB、总展开 1 GiB、压缩比 200:1、单 XML 文档 64 Mi 字符；XLSX 单行最多 16,384 列、共享字符串表最多 1,000,000 项；PPTX 默认最多 2,000 张幻灯片、每页最多提取 2 Mi 字符。
- 当前 Provider 仅以共享只读方式打开文件，不写入源文件。
- 导出通过独立只读 Provider 流式生成同目录临时文件并原子替换目标，不改写源文档；打印仅使用当前已安全载入的视图，单次最多 2 Mi 字符。
- 宏、脚本、OLE 对象不执行；PPTX 内嵌视频由用户点击后交给程序内解码器，外链视频不读取。不打包或启动第三方 exe。
- 基础 Open XML Provider 仅读取所需部件；内嵌视频仅在点击时写入临时文件；禁止 DTD 和外部实体，不解析外部关系。
